# Data

- monthly_returns.csv - 60 months (5 years) of monthly returns across 14 assets, built from realistic annual return/volatility assumptions and a sector-aware correlation structure (equities correlate with each other more than with bonds, gold near-independent, etc.)
- asset_info.csv - asset name, sector, and the target annual return/volatility assumptions used to generate the return series

Not live market data. See the main README's Limitations section.
